# API contracts

## Implemented today — shared rules

Defined by src/api.ts and route groups; no OpenAPI schema, generated client, /v1 prefix or compatibility version is present.
Normal success is JSON; date records serialize as ISO strings. Mutations generally return {success:true}; creates return 201. Errors are {error:code}; Zod adds fields:[{path,message}] with 400. Unique violation → 409 already_exists; FK violation → 404 related_record_not_found; unknown error → 500 internal_error. Body limit is 128,000 bytes (413 request_too_large).
Public/auth handlers run before tenant middleware. Remaining unsafe requests require Origin exactly PUBLIC_URL. Authenticated requests resolve (issuer,subject) into a user/workspace, which can write new identity/workspace rows even for a GET. Login/logout require origin but precede identity middleware.

New connection attachment requires project ownership; legacy null-project connections can be reconnected from an already-linked project, but cannot gain new source attachments.

## Implemented today — monitoring endpoints

All paths below use /api and session workspace authorization except the authenticated provider webhook.

| ----------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |

| GET /monitor/connections/:provider/callback     | state/code; consumes state and exchanges/probes credentials; redirects to project Sources                                                |

| GET /sources/:id/metrics                        | Supported provider-native/observed metric definitions and advertised filters                                                             |
